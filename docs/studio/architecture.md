# Studio 架构

本文回答 Studio 怎么做。定位、术语和分期见 product.md。

## 1. 目标与约束

定位与边界见 product.md §1、§3。

## 2. 上下文与主机名

一级是侧栏，二级是页内导航或子页面，三级是页面区块。角色可见性见 §7.1。

- 顶栏：组织切换、全局搜索（联系人、消息）、通知中心、个人菜单（个人资料、语言、通知偏好、退出）。
- 侧栏：收件箱、发布、联系人、数据、工作流、素材库、连接、团队与设置。

## 3. 原则

暂无单独条目；数据规则见 §5。

## 4. 构件与目录

### 4.1 收件箱

- 会话列表：未分配、我的、全部。未分配按组分池。按渠道、标签、来源、会话类型筛选。按等待时长排序并标记超时。搜索联系人和消息内容。
- 聊天区：文字、图片、视频、语音、文件、位置、贴纸、按钮和卡片回复、分享进来的帖子、快拍回复和提及都要能显示。每条消息原文译文并排。消息状态：已发、送达、已读、失败及原因。引用回复、表情回应，对方撤回和编辑的显示。出站先译再发，译文可改。插入快捷回复、素材、模板。工作流发出的消息标注来自哪条工作流第几步。
- 主动发起：WhatsApp 用模板向手机号发起新会话。Messenger 和 Instagram 不能主动发起，只能等客户先发。
- 内部备注：会话内成员可见、客户看不到的备注。
- 翻译：入站译成成员语言，出站译成客户语言。语言自动识别，可手动指定。按字符计量。
- 接管与分配：接管、转交给成员或组、释放。未分配池。自动分配规则按渠道、会话类型、在线状态、接待上限。成员在线状态。
- 接待：自动开始，手动结束、转交或 7 天无消息自动结束。
- 窗口：显示能否自由回复和剩余时间。过期后 WhatsApp 只能发模板；Messenger 和 Instagram 用人工客服标签还能发 7 天，之后要等客户再发。
- 通知：新消息、分配给我、转交给我、超时未回复。浏览器通知和声音，可按成员设置。
- 评论会话：帖子和广告下的评论以会话出现。回复、隐藏、删除、标记垃圾。私信评论者，每条评论一次，7 天内。可转给聊单组。
- 右侧栏：联系人资料、平台身份、来源、标签、备注、历史会话、接待记录。

页面：

- 视图栏
  - 未分配（按组）
  - 我的
  - 全部
  - 评论
  - 按渠道
- 会话列表
  - 筛选：渠道、标签、来源、类型、成员
  - 排序：最新、等待最久
  - 搜索
  - 每项：头像、名称、平台图标、最后一条消息、等待时长、未读数、标签、接管人
- 聊天区
  - 头部：联系人名、平台、渠道、窗口状态和剩余时间、接管 / 转交 / 释放 / 结束接待
  - 消息流：原文译文并排、消息状态、引用、表情回应、撤回和编辑标记、内部备注、工作流消息标注
  - 输入区：原文输入、译文预览可改、快捷回复、素材、模板、附件、内部备注切换、发送
- 右栏
  - 联系人：资料、平台身份及粉丝数
  - 来源
  - 标签
  - 备注
  - 历史会话
  - 接待记录
- 新会话：选 WhatsApp 渠道、输入手机号、选模板、填变量、发送

### 4.2 发布

- 帖子：文案、素材、按平台调整、首评、预览。支持帖子、快拍、Reels。TikTok 的隐私和 AI 标识等平台选项。
- 草稿和排期：草稿箱，日历，定时发布，多渠道一键。
- 发布记录：每渠道一条，状态，平台帖子 ID。失败原因和重试。
- 评论转私信：在帖子上配置，关键词或任意评论触发，私信内容，可延迟。仅 Instagram 和 Facebook。
- 帖子数据：平台曝光互动，加评论会话数、私信数、联系人数、标签统计。
- 引流链接：为帖子或渠道生成带参数的 m.me、ig.me 链接，wa.me 预填代号链接，二维码。进来的会话记为链接来源。

页面：

- 日历：月视图、周视图，拖动改期
- 帖子列表：草稿、已排期、已发布、失败；筛选渠道
- 新建帖子
  - 选渠道（多选）
  - 文案，按平台差异化
  - 素材（从素材库或上传）
  - 类型：帖子、快拍、Reels
  - 平台选项：首评、TikTok 隐私和 AI 标识
  - 评论转私信：开关、关键词、私信内容、延迟
  - 引流链接：生成并插入
  - 预览
  - 立即发布 / 定时 / 存草稿
- 帖子详情
  - 发布记录：每渠道状态、平台链接、失败原因、重试
  - 平台数据：曝光、互动
  - 聊单数据：评论会话数、私信数、联系人数、标签统计
  - 评论转私信：规则和触发记录
  - 引流链接：链接、二维码、带来的会话数
- 评论转私信：所有规则列表、触发日志
- 引流链接：列表、新建（关联帖子或渠道）、二维码

### 4.3 联系人

- 列表：搜索，按标签、渠道、来源、最近联系筛选。
- 详情：平台身份及其粉丝数和认证状态、来源、标签、备注、会话历史。
- 订阅与屏蔽：退订状态，屏蔽骚扰联系人。
- 合并：手动合并两个联系人。
- 标签目录：组织级。批量打标签。
- 导入导出：CSV。

页面：

- 列表
  - 筛选：标签、渠道、来源、最近联系、订阅状态
  - 搜索
  - 批量：打标签、导出
  - 导入 CSV
- 联系人详情
  - 资料：名称、备注名、备注
  - 平台身份：平台、账号名、粉丝数、认证、最近活跃
  - 来源列表
  - 标签
  - 订阅与屏蔽
  - 会话历史，按渠道
  - 合并到另一联系人
- 标签目录：新建、改名、颜色、删除

### 4.4 数据

- 来源：按广告、帖子、链接、直接看会话数、参与数、首次响应时间。按标签筛选。
- 广告：按广告看名称、系列、状态、花费、会话数、参与数、评论数。数据来自只读连接的广告账户。
- 团队：按成员和组看接待数、会话数、首次响应时间、在线时长。
- 渠道：按渠道看会话量、消息量、粉丝增长、曝光互动。
- 导出：各视图导出 CSV。

页面：

- 概览：会话数、参与数、首次响应时间、接待数，时间范围
- 来源：广告 / 帖子 / 链接 / 直接 × 会话数、参与数、首次响应；标签筛选；点击跳收件箱
- 广告：广告名、系列、状态、花费、会话数、参与数、评论数
- 帖子：帖子 × 曝光、互动、评论会话、私信、联系人、标签统计
- 团队：成员 / 组 × 接待数、会话数、首次响应、在线时长
- 渠道：渠道 × 会话量、消息量、粉丝增长、曝光互动
- 每个视图：时间范围、导出 CSV

### 4.5 连接

- 接入：Facebook 主页、Instagram、WhatsApp、TikTok。列表显示平台和名称，不显示统称。
- 状态：连接中、断开、被封提醒。断开后历史会话仍可看。
- 渠道详情：WhatsApp 的质量评级、发送层级、商务验证状态、业务资料。
- 能力标识：能聊、能发、能评论。TikTok 只能发。
- 广告账户：只读连接。来源里的 ad_id 由此变成广告名和系列名，花费由此拉取。

页面：

- 渠道列表：平台图标、名称、状态、能力标识（聊 / 发 / 评论）
- 接入新渠道：Facebook 主页、Instagram、WhatsApp、TikTok
- 渠道详情
  - 状态和断开原因
  - 成员权限
  - WhatsApp：质量评级、发送层级、商务验证、业务资料
- 广告账户：已连接列表、接入、允许同步的账户

### 4.6 工作流

- 第一版只有一种，跟进。进入：会话静默满 N 小时，且联系人没有成交类标签。步骤：第几天几点，发什么，内容从素材库选或现写。退出：客户回话，或打上成交类标签。
- 发送前查窗口：客户最后一条消息 24 小时内直接发；Messenger 7 天内用人工客服标签发；WhatsApp 用模板；都不行则结束。
- 有接管人的会话，工作流不向客户发消息。
- 一个组织一条默认工作流。存为可有多条的记录。
- 数据：每步发送数、回复数。
- 以后的种类：欢迎语、关键词回复、超时提醒、AI 接待。评论转私信配在帖子上，这里列出。

页面：

- 列表：名称、状态、进入人数、进行中人数
- 编辑
  - 进入条件：静默小时数、排除的标签
  - 步骤：第几天、几点、内容（文本、素材）
  - 退出条件：客户回话、成交类标签
- 数据：每步发送数、回复数
- 日志：每次发送一条，跳到会话

### 4.7 素材库

- 快捷回复：文本，多语言版本。窗口内用。
- 模板：WhatsApp 模板，按渠道管理。新建提交、审核状态、从 Meta 模板库导入。窗口外和主动发起时用。
- 媒体：图片、视频、文档。
- 聊天可插入，发帖可引用，工作流可引用。

页面：

- 快捷回复：分类、多语言版本、搜索
- 模板：按 WhatsApp 渠道切换；列表带状态；新建提交；从 Meta 模板库导入
- 媒体：图片、视频、文档；上传、搜索

### 4.8 团队与设置

- 成员与角色：管理员、聊单、社媒。
- 组：聊单组、社媒组。私信会话默认分聊单组，评论会话默认分社媒组，可改。
- 权限：按模块，按渠道。
- 分配规则和接待上限。
- 翻译语言偏好。
- 通知偏好。
- 计费与用量：渠道数按天计量，翻译字符用量。

页面：

- 成员：组、渠道权限、接待上限、在线状态（列表、邀请、组织角色和 Studio 访问在账号中心）
- 组：聊单组、社媒组，新增组，默认分配类型
- 分配规则：私信和评论会话的默认去向、自动分配开关、按渠道规则
- 翻译：成员语言、默认客户语言、自动翻译开关
- 通知：组织默认通知规则
- 用量：渠道数、翻译用量（套餐和账单在账号中心）
- 组织：时区（名称和 logo 在账号中心）

### 4.9 以后

群发：WhatsApp 模板。AI 辅助：回复建议、会话摘要。广告：管理员暂停恢复广告，把帖子推成点进私信的广告。回传成交给广告平台。WhatsApp 通话。Messenger 菜单和欢迎语。开放 API。移动端。

## 5. 运行时与契约

### 5.1 联动

| 触发                                  | 影响                                                                                   |
| ------------------------------------- | -------------------------------------------------------------------------------------- |
| 接入渠道                              | 收件箱出现该渠道会话；发布可选该渠道；数据按渠道统计；计费当天开始                     |
| 渠道断开或被封                        | 该渠道会话标记不可回复，历史可看；排期中该渠道的发布失败并提醒；计费停止               |
| 连接广告账户                          | 来源里的 ad_id 显示为广告名；数据广告视图有花费；广告评论进收件箱                      |
| 成员渠道权限变化                      | 只看到有权限渠道的会话，只能向这些渠道发帖                                             |
| 帖子发布成功                          | 生成发布记录；该帖评论进收件箱，来源为帖子；帖子数据开始累计                           |
| 评论转私信触发                        | 生成私信会话，来源沿用帖子，进聊单组的分配                                             |
| 引流链接被点                          | 会话来源为链接，关联到帖子或渠道                                                       |
| 入站消息                              | 新建或续接会话；进未分配池或按规则分配；接待开始；翻译；推送给在线成员                 |
| 客户发第二条消息                      | 参与数加一                                                                             |
| 成员首次回复                          | 记首次响应时间                                                                         |
| 接管、转交、释放                      | 写接待记录；未分配池变化；团队数据变化                                                 |
| 私信评论者                            | 从评论会话生成私信会话，来源沿用帖子                                                   |
| 打标签                                | 联系人标签变化；数据和帖子数据按标签的统计变化                                         |
| 合并联系人                            | 平台身份、会话、来源合并，标签取并集                                                   |
| 标签目录改名或删除                    | 所有联系人、筛选、数据同步                                                             |
| 导入带手机号的联系人                  | 匹配已有 WhatsApp 平台身份，关联历史会话                                               |
| 成员离线或被删除                      | 其接待中的会话按规则转交或回未分配池；自动分配跳过                                     |
| 接待上限或组变化                      | 自动分配立即按新规则                                                                   |
| 翻译一条消息                          | 计翻译字符用量                                                                         |
| 会话静默满 N 小时且联系人无成交类标签 | 进入工作流                                                                             |
| 工作流到点发消息                      | 先查窗口，按结果直接发、用人工客服标签发、用模板发或结束；会话里出现一条标注来源的消息 |
| 客户回话或打上成交类标签              | 退出工作流                                                                             |
| 有人接管会话                          | 工作流停止向该会话发消息                                                               |
| 快捷回复有客户语言版本                | 直接发该版本，不再翻译                                                                 |
| 数据里点某条广告或帖子                | 跳到收件箱，筛出它带来的会话                                                           |

### 5.2 数据规则

- 来源挂在会话的第一条入站消息上。联系人显示其所有平台身份的来源。来源类型：广告带 ad_id、标题、素材、ctwa_clid、预填文字；帖子带发布记录或平台帖子 ID；链接带 ref 参数或预填代号；直接。
- 标签是唯一分类。不建成交、订单、阶段。数据按标签筛选。
- 消息保存原文和译文。
- 会话分私信和评论两种类型。
- 平台原始报文全部保存。
- 平台的媒体链接会过期，Studio 保存媒体副本。

## 7. 横切

### 7.1 角色与导航

| 角色   | 落地页 | 可见模块                       |
| ------ | ------ | ------------------------------ |
| 管理员 | 数据   | 全部                           |
| 聊单   | 收件箱 | 收件箱、联系人、素材库         |
| 社媒   | 发布   | 发布、收件箱的评论会话、素材库 |

侧栏顺序按使用频率：收件箱、发布、联系人、数据、工作流、素材库、连接、团队与设置。工作流只有管理员可见。模块可见性由权限决定，不做隐藏逻辑。没有可发布渠道的组织，发布页显示接入引导。
