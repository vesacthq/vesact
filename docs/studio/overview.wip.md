# Studio

跨境卖家的社媒聊单产品：内容引流，私信聊单，翻译与 AI 辅助成单。

术语见 vocabulary.wip.md，模块见 architecture.wip.md，页面见 site-map.wip.md。

## 用户与路径

| 用户       | 入口                                            | 聊                               | 结果                              | 团队                              |
| ---------- | ----------------------------------------------- | -------------------------------- | --------------------------------- | --------------------------------- |
| 保健品卖家 | Meta 广告点进 Messenger，第一句话带招呼和产品名 | Messenger 聊单，发第三方付款链接 | 付款后履约，之后引到私人 WhatsApp | 30 到 100 人，要分配和管控        |
| 工厂外贸   | 社媒帖子，主页按钮进 WhatsApp                   | WhatsApp 报价                    | 下单、寄样                        | 社媒部和业务部两拨人              |
| 跨境圈子   | 自己找达人和老客                                | WhatsApp 沟通                    | 合作、复购                        | 小团队，重联系人管理，TikTok 发布 |

## 产品逻辑

一条链：入口把人带进来 → 私信里翻译着聊 → 结果打标签 → 数据看哪个入口值钱。

入口三种：广告是花钱买的，帖子是自己做的，链接和二维码是自己放的。发布模块生产帖子这一种入口。收件箱是所有入口的出口，是产品中心。

发布和聊单靠六个接点连成一个产品：

1. 帖子下的评论就是会话，在收件箱处理。
2. 帖子页显示它带来的评论会话数、私信数、联系人数和标签统计，内容用生意衡量。
3. 会话和联系人显示来源。
4. 评论转私信在帖子上配置。
5. 素材库共用，发帖的图和文案聊天时一键发出。
6. 数据一张表，广告和帖子用同一组指标。

## 边界

- 渠道层按 Zernio 的接口定义调用，webhook 也是接口的一部分。以后自己实现同一套接口，换地址。
- 接待、分配、接管由 Studio 管理，不依赖渠道层。
- 不建广告。
- 第一版不回传。保存 PSID、ad_id、ctwa_clid。
- 翻译不做术语库。
- AI 只占位。
- 工作流第一版只有跟进一种。调度由 Studio 做，渠道层只负责发送。
- TikTok 只发布不聊天。
- 定价：每渠道每月 18 元，翻译和 AI 按量。收款方式未定。

## 分期

1. 连接 Facebook 主页，收发文字，会话列表。
2. 翻译双向，原文译文并存。
3. 接管、接待、未分配池、自动分配、接待上限、组、渠道权限。保健品卖家可上团队。
4. 工作流，跟进。
5. 来源和数据，广告花费。
6. Instagram 和 WhatsApp 渠道。
7. 发布、排期、发布记录、评论会话、评论转私信、引流链接。工厂外贸可用。
8. 计费计量。
