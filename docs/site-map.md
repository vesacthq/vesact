# Studio 站点结构

一级是侧栏，二级是页内导航或子页面，三级是页面区块。角色可见性见 product-architecture.md。

## 全局

- 顶栏：组织切换、全局搜索（联系人、消息）、通知中心、个人菜单（个人资料、语言、通知偏好、退出）。
- 侧栏：收件箱、发布、联系人、数据、工作流、素材库、连接、团队与设置。

## 收件箱

- 视图栏
  - 未分配（按组）
  - 我的
  - 全部
  - 评论
  - 按渠道
- 会话列表
  - 筛选：渠道、标签、来源、类型、成员
  - 排序：最新、等待最久
  - 搜索
  - 每项：头像、名称、平台图标、最后一条消息、等待时长、未读数、标签、接管人
- 聊天区
  - 头部：联系人名、平台、渠道、窗口状态和剩余时间、接管 / 转交 / 释放 / 结束接待
  - 消息流：原文译文并排、消息状态、引用、表情回应、撤回和编辑标记、内部备注、工作流消息标注
  - 输入区：原文输入、译文预览可改、快捷回复、素材、模板、附件、内部备注切换、发送
- 右栏
  - 联系人：资料、平台身份及粉丝数
  - 来源
  - 标签
  - 备注
  - 历史会话
  - 接待记录
- 新会话：选 WhatsApp 渠道、输入手机号、选模板、填变量、发送

## 发布

- 日历：月视图、周视图，拖动改期
- 帖子列表：草稿、已排期、已发布、失败；筛选渠道
- 新建帖子
  - 选渠道（多选）
  - 文案，按平台差异化
  - 素材（从素材库或上传）
  - 类型：帖子、快拍、Reels
  - 平台选项：首评、TikTok 隐私和 AI 标识
  - 评论转私信：开关、关键词、私信内容、延迟
  - 引流链接：生成并插入
  - 预览
  - 立即发布 / 定时 / 存草稿
- 帖子详情
  - 发布记录：每渠道状态、平台链接、失败原因、重试
  - 平台数据：曝光、互动
  - 聊单数据：评论会话数、私信数、联系人数、标签统计
  - 评论转私信：规则和触发记录
  - 引流链接：链接、二维码、带来的会话数
- 评论转私信：所有规则列表、触发日志
- 引流链接：列表、新建（关联帖子或渠道）、二维码

## 联系人

- 列表
  - 筛选：标签、渠道、来源、最近联系、订阅状态
  - 搜索
  - 批量：打标签、导出
  - 导入 CSV
- 联系人详情
  - 资料：名称、备注名、备注
  - 平台身份：平台、账号名、粉丝数、认证、最近活跃
  - 来源列表
  - 标签
  - 订阅与屏蔽
  - 会话历史，按渠道
  - 合并到另一联系人
- 标签目录：新建、改名、颜色、删除

## 数据

- 概览：会话数、参与数、首次响应时间、接待数，时间范围
- 来源：广告 / 帖子 / 链接 / 直接 × 会话数、参与数、首次响应；标签筛选；点击跳收件箱
- 广告：广告名、系列、状态、花费、会话数、参与数、评论数
- 帖子：帖子 × 曝光、互动、评论会话、私信、联系人、标签统计
- 团队：成员 / 组 × 接待数、会话数、首次响应、在线时长
- 渠道：渠道 × 会话量、消息量、粉丝增长、曝光互动
- 每个视图：时间范围、导出 CSV

## 工作流

- 列表：名称、状态、进入人数、进行中人数
- 编辑
  - 进入条件：静默小时数、排除的标签
  - 步骤：第几天、几点、内容（文本、素材）
  - 退出条件：客户回话、成交类标签
- 数据：每步发送数、回复数
- 日志：每次发送一条，跳到会话

## 素材库

- 快捷回复：分类、多语言版本、搜索
- 模板：按 WhatsApp 渠道切换；列表带状态；新建提交；从 Meta 模板库导入
- 媒体：图片、视频、文档；上传、搜索

## 连接

- 渠道列表：平台图标、名称、状态、能力标识（聊 / 发 / 评论）
- 接入新渠道：Facebook 主页、Instagram、WhatsApp、TikTok
- 渠道详情
  - 状态和断开原因
  - 成员权限
  - WhatsApp：质量评级、发送层级、商务验证、业务资料
- 广告账户：已连接列表、接入、允许同步的账户

## 团队与设置

- 成员：列表、邀请、角色、组、渠道权限、接待上限、在线状态
- 组：聊单组、社媒组，新增组，默认分配类型
- 分配规则：私信和评论会话的默认去向、自动分配开关、按渠道规则
- 翻译：成员语言、默认客户语言、自动翻译开关
- 通知：组织默认通知规则
- 计费与用量：套餐、渠道数、翻译用量、账单
- 组织：名称、时区
