更新日期：2026 年 9 月 22 日

Vesact 是由西安速准科技有限公司（「运营方」「我们」）运营的 API 平台，开发者可以把自己客户的消息与社交媒体账号接进来，通过 `api.vesact.com` 的一套 API 使用它们，并在 `console.vesact.com` 的控制台管理。本政策说明哪些个人数据会经过本服务、为什么，以及你可以怎么处理它们。联系方式：[hello@vesact.com](mailto:hello@vesact.com)。

## 涉及谁

- **开发者**：登录控制台、创建组织、签发 API key 的人。
- **已连接账号的持有者**：授权某个平台账号（Facebook 主页、Instagram 专业账号、WhatsApp Business 号码）给开发者的应用通过 Vesact 使用的企业或个人。
- **终端用户**：给已连接账号发消息或与之互动的人。我们不会联系他们；他们的数据只以下文所述的平台事件形式到达我们。

## 处理哪些数据

**控制台账号。** 姓名、邮箱、用于登录的 Google 账号标识；所属组织及其名称和成员角色；发出或收到的邀请；会话记录（哈希后的令牌、IP 地址、浏览器 UA、时间）。

**API key 与用量。** key 以哈希形式保存，连同前缀、名称、权限范围和有效期。对 `/v1` 的每次请求都会记录 key、路由、状态、耗时和请求 id，用于限流、配额、计费和排障。你发送的幂等键会与对应响应一起保留 24 小时。

**已连接账号。** 账号通过 Vesact 授权时，平台会给我们该账号的标识和名称、授予的权限和访问令牌。我们保存这些以便代表开发者操作该账号，并向开发者反映连接是否健康。账号连接按平台逐个上线；某平台上线前，其用户的这类数据不会到达我们。

**平台事件与 API 内容。** Meta 等平台推送给我们的消息、评论、投递回执等事件会连同 payload 一起保存，以便送到开发者的 webhook 端点、失败重试，以及让开发者在控制台查看。通过 API 发送的内容（消息、帖子、媒体引用）在执行请求时处理，并随请求记录保存。

**运维。** 带请求 id、IP 地址和 UA 的服务器日志；本官网的访问分析（页面访问），经我们自己的域名收集，不含广告标识。

## 为什么处理，依据是什么

我们处理这些数据是为了提供你或你的组织要求的服务（履行合同）、保障安全、计费、遵守各平台条款和法律；产品分析基于我们了解产品使用情况的正当利益。我们不出售个人数据，不用于广告。

## 平台数据

从 Meta（Facebook、Instagram、WhatsApp）、TikTok、Google 等平台取得的数据只用于提供账号持有者授权的功能，并遵守各平台的开发者条款，包括 Meta 平台条款。通过 Vesact 获得平台数据的开发者须在同样的范围内使用。

## 还有谁能看到

服务运行在代我们处理数据的第三方基础设施上：

- **Cloudflare**（托管与网络）
- **Neon**（数据库，位于新加坡）
- **PostHog**（官网访问分析）
- **Google**（控制台登录；本官网从 Google Fonts 加载的字体）

持有已连接账号的开发者组织会收到与该账号相关的事件和内容。法律要求时，我们向主管机关披露数据。

## 跨境传输

运营方位于中国；上述基础设施位于新加坡、美国和 Cloudflare 的全球网络。使用本服务即表示接受数据在这些地点处理。

## 保留期限

控制台账号、组织、API key、用量记录和平台事件在组织存续期间保留，随组织删除，或按请求提前删除（见[数据删除说明](/legal/data-deletion)）；会计所需的用量按税法要求的期限保留。会话记录随会话过期；幂等记录 24 小时后不再使用；访问令牌在连接移除时删除。事件和请求记录的固定保留期限，待自动清理就位后公布。

## 你的权利

你可以访问、更正、导出和删除自己的数据。开发者在控制台操作；已连接账号的持有者可在平台侧撤销授权，或联系连接该账号的开发者；任何人都可以写信到 [hello@vesact.com](mailto:hello@vesact.com)。删除的具体方式见[数据删除说明](/legal/data-deletion)。根据你所在的地区，你还可能有权反对或限制处理，以及向监管机构投诉。

## Cookie

控制台使用一个会话 cookie 和一个记住语言的 cookie。本官网使用语言 cookie 和 PostHog 的第一方访问分析 cookie，它只向我们标识一个浏览器。这些 cookie 都不用于广告或跨站跟踪。

## 变更

变更会发布在本页并更新日期。重大变更会在控制台通知。
