## 1. 服务内容

Vesact 让你把自己或客户控制的消息与社交媒体账号接进来，通过一套 API 使用：接收事件、发送消息、发布内容、读取指标，范围以各平台允许为限。可用的平台和功能以控制台和文档为准，会随时间变化。

使用 API 需要控制台账号和组织。妥善保管登录方式和 API key；用你的 key 做的一切都视为你的组织所为。key 泄露时立即告知我们以便吊销。组织所有者决定谁是成员、能做什么。

## 3. 你的责任

你对基于本服务构建的应用和接入的账号负责。你应当：

- 只接入你有权操作的账号，并取得账号持有者和法律要求的一切同意；
- 遵守通过 Vesact 使用的各平台的条款，包括 [Meta 平台条款](https://developers.facebook.com/terms/)与开发者政策，以及适用时的 WhatsApp Business 消息政策；

- 不绕过限流、配额、认证或平台限制，不访问其他组织的数据。

违反上述规则或平台要求暂停的，我们可以暂停 key 或账号。

你可随时在控制台删除组织；你违约时我们可以通知后终止，情节严重或平台要求时立即终止。终止后 key 失效，数据按[隐私政策](/legal/privacy-policy)和[数据删除说明](/legal/data-deletion)删除。
